# Agent bundles

This repository will compile original Agent Skills and AGENTS.md instructions into platform-specific release ZIPs for Claude Code, Pi, DeepSeek Harness (DSH), Codex (Agent Plugins), and generic Open Agents-compatible clients.

The project is a plugin/skills bundle, **not an agent runtime**. Packaging validation is not a benchmark of task success. See the upcoming bundle implementation and tests for the release asset contract.
