# Creation quality, evidence and low-friction execution

Agent Brain adds four distinct creation/evidence procedures alongside its existing quality and focus candidates: `interface-craft` develops usable flows, `change-resilience` protects multi-step extension paths, `source-fidelity` checks claims against sources, and `contract-first-integration` reconciles APIs and state owners **before** coordinated implementation. They do not replace independent review or behavioral testing.

`focus-support` remains opt-in and can expose one executable starting action while preserving requested technical depth. `focus-continuity` uses the existing project plan and handoff to recover the exact next step after interruptions, without retaining health-related details or starting background work.

These are authored procedures, **not measured performance improvements**. Controlled external validation remains necessary.
