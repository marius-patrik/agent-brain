# Research and provenance

Custom-authored procedures informed by the following sources; no vendored upstream code or third-party runtime is required.

- [AGENTS.md](https://agents.md/) and [Agent Skills](https://agentskills.io/specification): portable instruction formats.
- [Everything Claude Code](https://github.com/affaan-m/everything-claude-code): agent specialization and learning.
- [Superpowers](https://github.com/obra/superpowers): planning, debugging, testing and review.
- [Anthropic Skill Creator](https://github.com/anthropics/skills/tree/main/skills/skill-creator): skill writing and evaluation.
- [OpenAI Agent Plugins](https://developers.openai.com/plugins/build/plugins): portable plugin packaging.
- [Pi packages](https://pi.dev/docs/latest/packages): declared skills.
- [DSH filesystem skills](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/skill/skill-filesystem): .agents/skills discovery.

Upstream hackathon or benchmark outcomes do not establish performance improvement of this bundle. Controlled matched A/B trials are required. Respect source licenses before incorporating upstream implementation material.
