# Research and provenance

Custom-authored procedures informed by the following sources; no vendored upstream code or third-party runtime is required.

- [AGENTS.md](https://agents.md/) and [Agent Skills](https://agentskills.io/specification): portable instruction formats.
- [Everything Claude Code](https://github.com/affaan-m/everything-claude-code): agent specialization and learning.
- [Superpowers](https://github.com/obra/superpowers): planning, debugging, testing and review.
- [Anthropic Skill Creator](https://github.com/anthropics/skills/tree/main/skills/skill-creator): skill writing and evaluation.
- [OpenAI Agent Plugins](https://developers.openai.com/plugins/build/plugins): portable plugin packaging.
- [Pi packages](https://pi.dev/docs/latest/packages): declared skills.
- [DSH filesystem skills](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/skill/skill-filesystem): .agents/skills discovery.

Upstream hackathon or benchmark outcomes do not establish performance improvement of this bundle. Controlled matched A/B trials are required. Respect source licenses before incorporating upstream implementation material.

## Quality and focus research references

These are **inspiration and evaluation leads**, not vendored code or evidence that Agent Brain improves task outcomes.

- [Anti Slop](https://github.com/miqdadbadjuber/anti-slop): task-aware critique of generic code, UI and copy.
- [no-slop-design](https://github.com/agshinrajabov/no-slop-design): reference-driven visual choices and product-specific direction.
- [no-slop](https://github.com/soheilmomeniii/no-slop): source-fidelity checks before stylistic editing.
- [i-have-adhd](https://github.com/Alamator/i-have-adhd): action-first optional communication; ours deliberately avoids invented time estimates and rigid list caps.
- [Claude Code ADHD Skills](https://github.com/Citability/claude-code-adhd-skills): Git-grounded progress and knowledge recovery, not an independent task runtime.
- [ADHD divergent ideation](https://github.com/UditAkhourii/adhd): contrasting candidate frames and critical convergence; we use a bounded portable procedure instead of its agent SDK.

No claims of medical benefit or controlled performance uplift are made; model evaluations are required before promotion as benchmark-proven techniques.

## Additional quality and contract research

- [SlopCodeBench](https://arxiv.org/abs/2603.24755): iterative specification checkpoints expose maintainability erosion that single-shot pass/fail tests miss. These are third-party study findings, **not** Agent Brain results.
- [Agent Skills format specification](https://agentskills.io/specification): discoverable descriptions and progressively loaded skill bodies; keep instructions concise and host-neutral.
- [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines): grounded interface accessibility and interactive-state review.

The additional `interface-craft`, `change-resilience`, `source-fidelity`, and `contract-first-integration` procedures are written for Agent Brain, not copied from those sources.
