# Goal

Maintain a custom-owned, standards-based agent-quality bundle for coding agents, compiled as versioned release archives for Claude Code, Pi, DeepSeek Harness, Codex and generic Open Agents clients.

This product is a bundle of reusable instructions, skills and role briefs, **not** a runtime, model router, daemon or MCP marketplace. Platform overlays are generated from one authoritative source. Delivery is successful when compiled archives are independently installable and structurally verified; improved agent outcomes require separate controlled benchmarks.
