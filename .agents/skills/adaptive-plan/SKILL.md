# Adaptive Plan

1. Derive necessary deliverables from the request; reject speculative features.
2. Partition by verifiable outcomes, not arbitrary equal-sized chunks.
3. Identify dependency edges and disjoint parallelizable writes; serialize shared contracts and integration.
4. Replan on evidence changes; regenerate docs and run integrated checks before completion.

**Integration:** Use `focus-continuity` when interruptions, competing discoveries or long-running execution threaten the active outcome. Keep plan ownership here; do not build a second task tracker. For unresolved consequential choices, `divergent-ideation` may precede planning within an authorized budget.

**Evidence:** report only actual actions and observable results. Do not override higher-priority host permissions or project requirements.
