# Source Fidelity

Own **claim-to-evidence fidelity**. `context-and-tools` selects and retrieves sources; this skill checks what they actually support.

## Procedure

1. **Identify claims:** separate direct observations, externally sourced assertions, estimates, interpretations and proposals. Determine which require primary evidence, dates, version pins or a qualified uncertainty label.
2. **Read the evidence:** inspect enough of the original source to preserve its scope, preconditions, methodology and limitations. Prefer primary documentation, actual artifacts and independent reproduction over marketing or repeated secondary summaries.
3. **Map claim to support:** for each consequential statement, record a source location (file path/line, URL/section, release SHA or study reference). Check that attribution and numbers match; distinguish publication dates from event dates and old versions from current ones.
4. **Challenge contradictions:** if sources disagree, explain the disagreement and the unresolved premise. Search narrowly for discriminating evidence rather than laundering uncertainty into a confident composite.
5. **Write faithfully:** paraphrase with meaning intact; quote only when needed and check wording. Do not invent page numbers, links, command results, benchmark improvements, citations or consequences not supported by the cited material.
6. **Check currency:** for evolving libraries, APIs, product behavior, security rules or current events, refresh time-sensitive claims and explicitly state what could not be verified.
7. **Review output:** remove generic filler or unsupported rhetorical emphasis using `quality-without-slop`. A polished sentence that overstates the source is still incorrect.

## Evidence boundary

When evaluating Agent Brain itself, report measured task success separately from installation, generated code quality, simulated examples and third-party study results. Research findings are candidates for testing, not measured improvements of this bundle.

For a question that needs no external sources, answer without staging an unnecessary research project.
